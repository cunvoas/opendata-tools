# Security Policy

## Supported Versions

Dependabot was used but replaced by Github Advanced Security.
Snyk & Deepsource was add to enforce audit.

| Version | Supported          |
|---------|--------------------|
| 2.0.13  | :x:                |
| 1.0.19  | :x:                |
| 1.0.15  | :white_check_mark: |

## Reporting a Vulnerability

Do not open a public issue for a security vulnerability. Report it privately through [GitHub private vulnerability reporting](https://github.com/cunvoas/opendata-tools/security/advisories/new).

Include a short description of the problem, the affected file or dependency, and the CVE/GHSA identifier if one exists.

Reports are tracked in the [Security tab](https://github.com/cunvoas/opendata-tools/security).
